# 🧩 Word Puzzle Game for iOS

A visually engaging and interactive **word puzzle game** for iOS, built entirely with **SwiftUI**. The game challenges players to form words from a set of scrambled letters, offering:

- ✨ An intuitive and modern user interface  
- 📱 Adaptive layout for all iPhone and iPad devices

## 🚀 Features

- SwiftUI-powered declarative UI
- Dynamic layout adapting to different screen sizes and orientations
- Progress tracking

## 📱 Requirements

- iOS 15.0+  
- Xcode 13.0+  
- Swift 5.5+
